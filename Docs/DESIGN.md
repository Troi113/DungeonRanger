# Design Direction

## Reference
Use the original Watabou Pixel Dungeon source as an architectural and gameplay reference, not as code to translate line by line. Implement with C#, Unity scenes, GameObjects, prefabs, ScriptableObjects where useful, and the Input System.

## Planned game
- Real-time WASD movement and combat.
- One ranger class only.
- Four procedural dungeon levels plus a fifth boss level.
- Procedural room-and-corridor dungeon inspired by Pixel Dungeon.
- Separate boss arena or strongly constrained boss layout.
- Original game identity, visuals, names, and content.

## Priorities
1. Playability first, with primitive visuals and simple systems.
2. Polish, generated art, audio, and extra content only after the core loop works.

## Licensing
Respect the original Pixel Dungeon license and attribution requirements if any source, asset, or design is reused. Prefer new Unity code and original assets.
